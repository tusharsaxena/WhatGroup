## The title-bar pass (rulings 3 and 4)

`modules/FrameLayout.lua`). Its title bar carries the title text and the drag, and **no control**:
the popup closes through its bottom **Close** text button (`UIPanelButtonTemplate`, skinned by

`NS.MakeCloseButton` seam in `core/CoreSetup.lua` is published but no window of this addon calls
it. So the addon owes no title-bar tooltip or color work and none was made; the debug console and
the other library windows it opens get theirs from the re-copy alone.
